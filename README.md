# Atividade de Estrutura de Dados em Árvore — Estrutura de Dados II

# Sobre o projeto  

O objetivo deste projeto foi implementar e manipular **estruturas de dados em árvore**, aplicando os conceitos de **árvore binária de busca (BST)** e **árvore AVL**, por meio da classe:  
- **CatalogArvore**  

O sistema representa um **catálogo de livros**, permitindo **inserir, buscar, remover e listar** livros de forma ordenada, com base em um **identificador único (ID)**.  

Além disso, foi implementada uma **nova funcionalidade** que permite **alterar o autor de um livro existente**, reforçando a manipulação de nós já presentes na estrutura.  

O projeto destaca os seguintes pontos:  

- **Inserção de livros (manual ou via arquivo .txt)**  
- **Busca por ID**  
- **Remoção de livros**  
- **Listagens em diferentes ordens (em-ordem, pré-ordem, pós-ordem e em largura)**  
- **Comparação entre desempenho da BST e AVL**  
- **Alteração de autor de livro já inserido**  

Mais do que reforçar a teoria, o código busca proporcionar uma **experiência prática de aprendizado**, unindo **conceitos de estrutura de dados** com **aplicações reais** e **interatividade via console**.

# Estrutura de entrada (arquivo de dados)  

O arquivo deve seguir o formato:  

```
ID;Título;Autor
```

### Exemplo:
```
1;Dom Casmurro;Machado de Assis
2;O Hobbit;J. R. R. Tolkien
3;1984;George Orwell
```
